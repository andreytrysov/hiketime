# Поставить HikeTime на свой iPhone

Единственное, что нельзя сделать без тебя: подпись приложения требует
твоего Apple ID. Платный аккаунт разработчика ($99/год) не нужен —
бесплатного хватает, только пересобирать раз в 7 дней.

## Один раз

1. Открой проект: `open ~/Documents/Claude/hiketime/app/HikeTime.xcodeproj`
2. Xcode → Settings → Accounts → «+» → Apple ID → войди своим.
3. В проекте слева выбери синюю иконку **HikeTime** → вкладка
   **Signing & Capabilities**:
   - поставь галочку **Automatically manage signing**;
   - в **Team** выбери свой Apple ID (будет «Andrey Trusov (Personal Team)»);
   - **Bundle Identifier** поменяй на уникальный, например
     `com.andreytrusov.hiketime.dev` — иначе Apple может ругаться,
     что идентификатор занят.

## Каждый раз

4. Подключи iPhone кабелем, разблокируй, на вопрос «Доверять этому
   компьютеру?» ответь «Доверять».
5. Вверху Xcode в выпадающем списке устройств выбери свой iPhone.
6. Нажми ▶ (Run).

## Первый запуск на телефоне

7. Приложение установится, но не откроется — iOS не доверяет
   подписи. На телефоне: **Настройки → Основные → VPN и управление
   устройством → Apple Development: (твой email) → Доверять**.
8. Запусти HikeTime с домашнего экрана.

## Что важно знать

- **Через 7 дней** приложение перестанет открываться («срок подписи
  истёк») — просто снова нажми ▶ в Xcode, данные не потеряются.
- **Кабель нужен только первый раз.** Дальше можно по Wi-Fi: Xcode →
  Window → Devices and Simulators → выбери iPhone → галочка
  «Connect via network».
- **Оффлайн-карты**: в приложении уже вшит район Церматта. Свой район
  качается через ⚙ → Оффлайн-карты → «Скачать видимую область»
  (при выключенном VPN — с ним ломается DNS).
- Чтобы раздать приложение тестировщикам без кабеля, нужен платный
  аккаунт разработчика и TestFlight. Пока для этого есть веб-прототип:
  https://andreytrysov.github.io/hiketime/
